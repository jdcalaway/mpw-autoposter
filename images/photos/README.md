# Drop your real photos here

Put JPGs (or PNG/WebP) into the folder that matches the content pillar. The
system automatically uses a real photo when one is available and falls back to
an auto-generated branded graphic when the folder is empty.

| Folder            | Use it for                                              |
|-------------------|---------------------------------------------------------|
| `transformation/` | Before/after grooming shots (your best content)         |
| `featured/`       | A great photo of a freshly groomed dog                  |
| `bts/`            | Inside/around the van, groomer at work                  |
| `testimonial/`    | A happy-dog photo to pair with a review, or a review pic |
| `booking/`        | The van in a driveway                                   |
| `tip/`            | Grooming-in-action photos                               |
| `engagement/`     | Cute candid dog photos                                  |

**Tips**
- Square (1080×1080) or portrait (1080×1350) JPGs look best on both platforms.
- Add as many as you like — the system rotates through them by date.
- Get client permission before featuring their dog.
- Commit the photos (they're served to Instagram from the repo's public URL).
